Read-only mode: only commands that cannot change anything run, and they may read outside the working directory. A command line may only chain and pipe these programs: ls, cat, head, tail, wc, sort, uniq, cut, tr, grep, rg, find (without -delete or -exec), jq, stat, file, du, df, date, echo, printf, pwd, env, which, realpath, basename, dirname, readlink, nl, tac, rev, paste, diff, cmp, comm, seq, checksums, and git subcommands that only look (status, log, diff, show, blame, branch --list, rev-parse, ls-files and the like). No output redirection to files, no command substitution, no variable assignments, no subshells or control flow; anything else is refused with the reason. Commands need no approval. Background runs are not available.
