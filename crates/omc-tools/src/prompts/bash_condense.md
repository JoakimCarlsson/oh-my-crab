The output of noisy commands (git, cargo, npm, pnpm, yarn, make, C compilers, go, pytest, docker, apt) is condensed: progress, build steps and passing tests are dropped or counted, while errors and warnings are always kept. A condensed stream ends with a note like `[stdout condensed: 412 lines → 38; the whole output is in <path>; …]`; read that file when you need what was left out.
