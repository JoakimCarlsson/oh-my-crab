The output of noisy commands (git status, push, pull, fetch and clone, cargo, npm, pnpm, yarn, make, C compilers, go, pytest, docker, apt) is condensed when the command is the last one on the line: progress, build steps and passing tests are dropped or counted, while errors and warnings are always kept and every other line is shown exactly as printed. `git log`, `git show` and `git diff` are never condensed. A condensed stream ends with a note like `[stdout condensed: 412 lines → 38; the whole output is in <path>; …]`; read that file when you need what was left out.
