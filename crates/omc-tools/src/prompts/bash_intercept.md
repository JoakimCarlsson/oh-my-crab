Use the dedicated tools rather than the shell for files: `read` to show a file or part of it (not `cat`, `head`, `tail` or `less`), `grep` to search contents (not `grep` or `rg`), `glob` to find files by name (not `find` or `ls -R`), `edit` to change a file (not `sed -i`) and `write` to create one (not `echo >` or `cat <<EOF >`). A command that is nothing but one of those uses is not run, and the result names the tool and the arguments to use; pipelines and commands that need the shell run as usual.
