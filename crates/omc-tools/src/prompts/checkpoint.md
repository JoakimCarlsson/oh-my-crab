Mark the current point in the conversation before a long investigation, so that `rewind` can later replace everything after it with a short report. Use it when the answer will take many reads, searches and dead ends that you will not need once you know it. Takes an optional `goal` saying what you want to find out. Only one checkpoint can be active at a time; calling it again before `rewind` fails. Call `rewind` before you finish your turn. This changes only your conversation history: files on disk are not touched or restored, so a rewind never undoes an edit.
